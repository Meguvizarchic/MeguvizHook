# 项目状态

MeguvizHook 当前为 `0.1.0-SNAPSHOT`，尚未作为正式稳定版本发布。源码包含 JVM Hook 核心、libxposed API101／102 后端、可选 Kotlin DSL、模块样例和显式诊断组件。

单目标替换支持关闭后的新调用拒绝及既有在途代次；跨目标不承诺原子性。API102 模块热重载需要框架支持及模块自行处理生命周期和资源交接；API101 没有同一模块热重载生命周期。具体限制见 [热重载接入](hot-reload-102.md)。

诊断批量和压缩需要调用方显式选择与配对。调用者提供后台执行、端点授权和接收队列，接收确认不等于持久化，失败后的显式重试可能重复。更多信息见 [异常诊断与远程传输](remote-diagnostics-102.md)。

本地 JVM 合同测试、后端桩测试、公开接口检查与限定 Android 制品构建已有覆盖；这些结果不等于真实设备、完整框架兼容或性能资格。批量／压缩的 Binder 运行时、跨进程故障恢复、进程重启后可靠性和端到端性能仍需另行验证。

仓库中的 API 描述和测试不代替调用方的目标授权、数据保护、保留和清理策略。
